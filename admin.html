Setup guide

One-time Firebase setup, then your daily classroom routine.

1. One-time setup (in Firebase Console)

  1. Authentication → Sign-in method → enable Email/Password AND Google
    ← without this you get "This sign-in method is not enabled yet"
  2. Authentication → Settings → Authorized domains → Add domain → localhost
    ← without this you get "This domain is not authorised"
  3. Firestore Database → Rules → paste firestore.rules → Publish
  4. Word bank tab → tick phrases → Write to Firestore
  5. Change the default password (Account tab)

2. Daily classroom routine

  1. Pupils open the app → enter seat no., name, class
  2. They practise for 5–10 minutes
  3. You press ⬇ Export CSV and save the file (do this every day)

3. ⚠️ Why export every day?

Firestore free tier allows 50,000 reads per day. One full export reads 40,000 documents — that is 80% of the day's quota. Exporting only the current day uses about 6,000 reads, so 7 daily files is safe.

4. How phrase blanking works

The article (a / an / the) is shown but never blanked — it is already known. Blanking targets the content words, ordered by spelling weight. For a post office: L1 blanks ff in office (doubled consonant, weight 73), L2 blanks the silent e, L3 moves to post.
